# Drel 1.4.0 私有离线应用真机验收

这份表只用于 **Drel 1.4.0 的精确 TestFlight 构建**。模拟器和单元测试已证明
签名、哈希、原子切换及断网后的本地文件解析；下列项目必须在真实 iPhone 上观察，
不能用模拟器结果代替。

## 验收前准备

- 当前修复候选构建为 `Drel 1.4.0 (64)`，使用 App Store 发布配置
  `Drel14Store / Drel14Release` 生成；上传后只验收这个精确构建。
- 准备一个仅供审核与测试使用的私有 HTTPS 演示应用。
- 父 Manifest 由已登记的 Ed25519 密钥签名，并绑定标准
  `manifest.webmanifest` 的准确 URL 与 SHA-256。
- `manifest.webmanifest` 的 `drel_offline` 与父 Manifest 完全一致；资源清单中
  HTML、CSS、JavaScript、图标均有大小和 SHA-256。
- 不复用正在审核的 1.0.x 构建，也不在本轮加入 Bridge。

## 放行规则

- P1–P12 全部通过，并记录设备型号、iOS 版本、Drel 版本和构建号。
- 商店截图必须是实际 App 界面；审核备注提供演示应用的导入步骤和有效测试材料。
- 任一签名、哈希、回滚、删除、断网启动或升级项失败，都不能提交 1.4.0 审核。
- 真机验收通过后，仍需在 App Store Connect 绑定同一个精确构建并获得当次提交确认。
