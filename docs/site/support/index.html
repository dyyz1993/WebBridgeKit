Getting started

Install Drel, allow notifications when prompted, then copy the personal push address shown on the Home screen. You can call that address from a browser, script, automation, or your own web service.

Open-source push service

The Drel push service is based on the open-source WebBridgeKit server. V1 uses the official Drel endpoint in the iOS app; gateway import, offline web-tool packages, and web-tool management are planned for later releases.

A notification did not arrive

  1. Confirm notifications are enabled for Drel in iOS Settings.
  2. Open Drel once after installation so it can complete registration.
  3. Check that your Drel push address is current and that api.drel.app is reachable.
  4. Try a short title and body without custom sound or route parameters.

An HTTPS page does not open

Confirm the target URL uses HTTPS and is reachable. Drel's first Store release does not install web tools, inject WebBridge.js, or allow remote pages to call native Bridge capabilities.

Security reports

Please send suspected vulnerabilities to security@drel.app. Do not include secrets, private keys, or full push tokens in screenshots or email.
