Security model in one minute

A push address is a bearer capability. Keep it out of screenshots, logs, source control and public URLs. The official delivery service processes the request in order to deliver it; it is not an end-to-end encrypted secret channel. Do not put credentials, recovery codes, financial data or private content in a notification title, body, route or URL.

What Drel does not do

  • A remote page does not receive native Bridge, file, photo-library, clipboard or approval powers merely because it opened in Drel.
  • A Web App Manifest alone does not make a page an offline app. Durable offline launch requires a verified package and a user-initiated install.
  • A successful API response means the relay accepted the request; it is not a guarantee that a particular device displayed it.
