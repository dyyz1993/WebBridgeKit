# 官方版快速开始

官方版安装后直接使用，不需要配置网关、服务器地址或手工创建推送 Key。系统通知授权是唯一必要交互。

## 1. 安装并打开

首页会在本机生成安全的推送身份，并自动连接官方服务。首次打开不会突然弹出系统授权，也不会要求填写技术配置。

## 2. 点一次“启用通知”

在首页点“启用通知”，确认 iOS 的系统授权。授权、APNs 注册和官方服务登记都成功后，首页才会显示可用的“我的推送地址”。如果拒绝过授权，首页会提供“前往系统设置”的恢复入口。

## 3. 复制地址或打开示例

复制首页地址即可发送普通通知；也可以打开“全部 API 示例”，直接测试 Markdown、验证码、二维码、图片、聊天与审批。Safari 示例会在应用外发起真实 HTTP 请求。

完整结构化字段见 [消息类型 v1](../api/message-types-v1.md)，审批状态和回调语义见 [Approval v1](../api/approval-v1.md)。推送地址相当于本设备的投递能力，请勿放进公开源码、截图或日志。审批推送只能定位待处理内容，应用仍会刷新状态并要求本人确认。

## 何时需要自部署

只有需要自管 PWA 网关、密钥或服务端的团队，才需要走 [自部署网关导入](self-hosted-gateway-import.md)。该流程由部署者提供一次二维码或配置文本，终端用户导入、验证并确认即可。
